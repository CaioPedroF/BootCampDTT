**README - Implementação de CRUD com Insomnia, Docker e DBeaver Descrição do Projeto**

Este projeto tem como objetivo implementar um CRUD (Create, Read, Update, Delete) utilizando as ferramentas Insomnia, Docker e DBeaver. O CRUD é uma funcionalidade básica para interação com um banco de dados, permitindo criar, ler, atualizar e deletar dados. Este projeto visa demonstrar a integração dessas ferramentas para facilitar o desenvolvimento e o gerenciamento de dados em uma aplicação.

**Tecnologias Utilizadas**

Insomnia: Ferramenta para testar APIs RESTful.

Docker: Plataforma para automatizar a implantação de aplicações em contêineres.

DBeaver: Ferramenta de gerenciamento de banco de dados, compatível com diversos tipos de banco de dados relacionais.

**Pré-Requisitos**

Docker: Certifique-se de que o Docker está instalado e configurado corretamente no seu sistema.

DBeaver: Instale o DBeaver para gerenciar o banco de dados.

Insomnia: Instale o Insomnia para testar as APIs RESTful.
